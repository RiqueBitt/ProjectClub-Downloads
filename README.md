# Project Club — Downloads

Os instaladores mais recentes ficam publicados como **Release** deste
repositório (aba "Releases" à direita), não mais como arquivos soltos
numa pasta — dá pra baixar direto pelo link estável abaixo, ou navegando
pela aba Releases no GitHub:

- Windows: `releases/latest/download/ProjectClub-Setup-Windows.exe`
- Linux: `releases/latest/download/ProjectClub-Linux.AppImage`
- Android: `releases/latest/download/ProjectClub.apk`

Publicado automaticamente pelo GitHub Actions do repositório principal
(privado) toda vez que o app muda.
