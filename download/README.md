# Downloads — Project Club

Esta pasta guarda os instaladores mais recentes de cada plataforma.

- `ProjectClub-Setup-Windows.exe` — Windows
- `ProjectClub-Linux.AppImage` — Linux
- `ProjectClub.apk` — Android

Publicados automaticamente pelo GitHub Actions do repositório principal
(privado) toda vez que a pasta `desktop/` ou `client/android/` muda —
mas como este é um repositório normal, também dá pra arrastar um arquivo
novo aqui manualmente a qualquer momento, se preferir atualizar na mão.
